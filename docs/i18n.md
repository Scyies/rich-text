# Internationalization (i18n)

The built-in chrome — slash menu, floating toolbar, table/image controls, the typing placeholder, and
ARIA labels — is localizable. The out-of-the-box default is **English**; switch with the
`locale` prop or override individual strings with `messages`.

## Switching locale

```tsx
import { DocumentEditor } from "wealthy-text-editor/react";

<DocumentEditor
  value={doc}
  onChange={setDoc}
  locale="pt-BR"
  // Optional: override individual strings on top of the resolved locale.
  messages={{ slashTable: "Grade" }}
/>;
```

Built-in locales are `en` (default) and `pt-BR`. The same props exist on `BlockEditor`.

## Advanced: resolving messages yourself

For a third language, or to compose the provider manually:

```ts
import { resolveMessages, MessagesProvider, useMessages } from "wealthy-text-editor/react";

// Merge a shallow override over a base locale:
const messages = resolveMessages("pt-BR", { slashNoResults: "Nada aqui" });
```

- `resolveMessages(locale?, override?)` returns a complete `EditorMessages`. With no arguments
  it returns the English dictionary.
- `MessagesProvider` / `useMessages` are the React binding (the editor wraps its subtree in the
  provider for you; use them only if you build custom chrome that should follow the locale).
- `en` and `ptBR` are the raw dictionaries; `DEFAULT_LOCALE` is `"en"`.

## The `EditorMessages` shape

`EditorMessages` is a flat record of strings (plus one function for the parametrized heading
label). It covers, among others:

- **Slash menu:** `slashHeading1`–`slashHeading3`, `slashText`, `slashBulletedList`,
  `slashNumberedList`, `slashTable`, `slashImage`, `slashNoResults`, `slashMenuAriaLabel`.
- **Editor chrome:** `placeholder`, `documentAriaLabel`, `addLineBelow`, `dragHandleTitle`,
  `expandSection`, `collapseSection`.
- **Blocks:** `headingAriaLabel(level: number) => string`, `textBlockAriaLabel`.
- **Toolbar:** `toolbarAriaLabel`, `markBold`, `markItalic`, `markUnderline`,
  `markStrikethrough`, `markCode`.
- **Table:** `tableCellAriaLabel`, `tableAddRow`, `tableRemoveRow`, `tableAddColumn`,
  `tableRemoveColumn`, `tableRowLabel`, `tableColumnLabel`.
- **Image:** `imageMissingSource`, `imageCaptionPlaceholder`, `imageCaptionAriaLabel`,
  `imageResizeAriaLabel`, `imageGroupSlotLabel`, `imageGroupAddColumnAriaLabel`,
  `imageGroupRemoveColumnAriaLabel`, `imageDropFailed`, `imageDropUrlDisabled`,
  `imageDropUnsupported`.
- **Chip popover:** `chipEditAriaLabel`.

A custom dictionary must provide every key; `resolveMessages(locale, override)` lets you supply
a partial override over a complete base, which is the recommended path.

## Plugin strings are the author's responsibility

Only the **core** chrome is localized. Strings authored by a plugin — its slash item label,
toolbar title, popover text — are not covered by `EditorMessages`. Localize them inside the
plugin if you need to (e.g. read your own locale and pick the label).
